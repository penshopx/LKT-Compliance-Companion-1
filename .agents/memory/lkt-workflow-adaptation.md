Adapt GUSTAFTA's relevant workflow ideas to annual financial and corporate reporting, not construction certification, tendering, branding, pricing, or marketing claims. The user chose “Ruang laporan dan diagnosis” as the first implementation package; document analysis/storage and install/theme are separate packages.

**Why:** The user requested features suited to LKTara's specific purpose and explicitly selected the first package rather than importing the entire construction platform.

**How to apply:** Readiness means self-reported preparation progress, never audited figures or legal compliance. Report-year selection must not silently change the company's active profile year. Preserve legacy checklist work for the same company/year rather than creating a second contradictory checklist.
